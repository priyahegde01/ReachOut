# Code Set-up - Server Side

### Pre-requisities:
You need to get few things set up before you can play with the server-side code.

- Run the following command to check if python is installed, if not, install python v3. <br> ``python --version`` <br>
- If python is installed, and you are not able to run python in your current directory, then run this command in your terminal in the ReachOut directory: <br>
``cd Server                                
python3 -m venv .venv
source .venv/bin/activate``
- Install the requirements: <br>
``python3 -m pip install -r requirements.txt`` <br>
